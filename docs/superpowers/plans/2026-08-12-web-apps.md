# 网页应用随系统部署（web-apps）实现计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 用声明式 app 模式（`google-chrome-stable --app=URL` 的 `.desktop` 文件 + 图标）把 DeepSeek / Kimi / Gmail / GitHub 作为可复现应用随 dotfiles 部署，并让 DeepSeek / Kimi 保留 scratchpad 窗口行为。

**Architecture:** 在 `dotfiles/.local/share/applications/` 放 4 个 `.desktop` 文件、`dotfiles/.local/share/icons/hicolor/256x256/apps/` 放 4 个 256px PNG，随现有 dotfiles 阶段 1:1 拷贝部署；`install.sh` 的 dotfiles 阶段追加桌面项/图标缓存刷新；hyprland.lua 用实测的 `--app` URL 推导类名写窗口规则。

**Tech Stack:** bash（install.sh）、Lua（hyprland.lua）、FDO `.desktop` / icon theme 规范、ffmpeg（图标缩放）、curl。

## Global Constraints

- 绝不运行 `./install.sh`（会改动系统状态）。本地验证用**手动 cp 到 `~/.local/share`** 模拟部署。
- 静态检查仅两项：`shellcheck install.sh`、`luac -p dotfiles/.config/hypr/hyprland.lua`。
- 不跑 `stylua`；hyprland.lua 保持 4 空格缩进 + 对齐 `=`。
- `.desktop` 不含 `StartupWMClass`（Wayland 下 Chrome 忽略，写了会误导）。
- 注释用中文。
- 图标统一 256x256 PNG，存 `hicolor/256x256/apps/`，`.desktop` 的 `Icon=` 用 basename（图标名）。
- 应用 URL（已验证可达）：
  - DeepSeek `https://chat.deepseek.com`
  - Kimi `https://www.kimi.com`（`kimi.moonshot.cn` 会 301 到这里）
  - Gmail `https://mail.google.com`
  - GitHub `https://github.com`

### Task 5: hyprland.lua 窗口规则（DeepSeek / Kimi scratchpad）

**Files:**
- Modify: `dotfiles/.config/hypr/hyprland.lua`（现有 Chrome PWA 规则块之后，约第 300-301 行 `suppress-maximize-events` 之前）

**Interfaces:**
- Consumes: Task 4 Step 4 实测的 DeepSeek / Kimi class（下文 `<DEEPSEEK_CLASS>` / `<KIMI_CLASS>` 用实测值替换）
- Produces: 两条窗口规则，DeepSeek / Kimi app 窗口浮动进 special 工作区

- [ ] **Step 1: 用实测 class 追加两条窗口规则**

Task 4 实测的类名（原文，勿改动）：
- DeepSeek：`chrome-chat.deepseek.com__-Default`
- Kimi：`chrome-www.kimi.com__-Default`

插在现有 `float-kimi` 规则之后：

```lua
-- 网页应用（app 模式，类名由 --app URL 推导，实测值见上）
hl.window_rule({
  name = "float-deepseek-web",
  match = { class = "^(chrome-chat\\.deepseek\\.com__-Default)$" },
  float = true,
  size = "1200 800",
  center = true,
  workspace = "special:deepseek silent",
})
hl.window_rule({
  name = "float-kimi-web",
  match = { class = "^(chrome-www\\.kimi\\.com__-Default)$" },
  float = true,
  size = "1200 800",
  center = true,
  workspace = "special:kimi silent",
})
```

> 说明：Hyprland 的 `match.class` 走正则引擎（与现有 `io\.github\.xiaoyifang\.goldendict_ng` 规则同风格），`\.` 转义点号、`-` 为字面量。类名里 `__` 是 URL 派生的原样字符。

Expected: 无输出（语法 OK）。
